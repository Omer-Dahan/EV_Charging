## 1. תקציר מנהלים ותמונת מצב בישראל

שוק עמדות הטעינה הציבוריות בישראל מתאפיין בביזור בין עשרות מפעילי עמדות טעינה פרטיים (**CPOs - Charge Point Operators**), לצד ניסיון ממשלתי לאיגום הנתונים תחת רגולציה ומאגר לאומי של משרד האנרגיה והתשתיות.

### תובנות מפתח מהמחקר:
1. **היעדר Public APIs פתוחים אצל המפעילים הפרטיים:** אף אחד מהמפעילים הישראליים המובילים (EV-Edge, Paz, Afcon, Sonol EVI, Gnrgy) אינו מספק "Developer Portal" או REST API ציבורי פתוח ללא עלות למפתחים עצמאיים. המערכות מבוססות אפליקציות מובייל סגורות המדברות עם שרתי Backend קנייניים, ותקשורת חומרה בפרוטוקול OCPP.
2. **מאגר data.gov.il פתוח, חינמי ומאומת:** ממשלת ישראל מפרסמת דרך פורטל data.gov.il מאגר נתונים פתוח (`agg_charge_stations`) הכולל **2,261 עמדות טעינה** (נכון לבדיקה פעילה) עם שאילתות JSON דרך CKAN datastore API. המאגר מכיל פילוח מפעיל, כתובת, וכמות עמדות מהירות/איטיות, אך ללא זמינות בזמן אמת.
3. **המאגר הלאומי של משרד האנרגיה (CelloCharge):** משרד האנרגיה הקים פלטפורמה לאומית המחייבת את המפעילים להזרים נתוני Real-time (זמינות, מחירים, תקלות, הספקים) בפרוטוקול OCPI. הגישה ל-API זה מחייבת הגשת בקשה רשמית וקבלת אישור ממשרד האנרגיה.
4. **מקורות גלובליים וקהילתיים (OSM / Open Charge Map):** מהווים גיבוי מצוין למיפוי גיאוגרפי מדויק, חיפוש מבוסס רדיוס (Lat/Lng) וסוגי תקעים.

## 2. סקירת מפעילי רשתות טעינה בישראל (CPOs)

### 2.1 EV Edge (יוניון מוטורס)
* **שם הספק:** EV Edge (חברת איוי אדג' בע"מ, מקבוצת יוניון)
* **URL רשמי:** [https://www.ev-edge.co.il](https://www.ev-edge.co.il)
* **נקודת קצה (Endpoint):** אין API ציבורי פתוח. הממשקים משרתים את אפליקציית המובייל (`EV-Edge`) ומערכות ניהול ציי רכב.
* **שיטת אימות (Authentication):** אימות קנייני סגור (Session / Bearer Tokens באפליקציה). גישה אינטגרטיבית לחברות וציי רכב מתבצעת ב-B2B תחת הסכם מסחרי.
* **חינם או בתשלום:** סגור לציבור; אינטגרציה עסקית בתשלום / שותפות מסחרית.
* **מגבלות קצב (Rate Limits):** מוגן בחומת אש (WAF) ובקרת קצב פנימית של האפליקציה.
* **זמינות בזמן אמת (Real-time availability):** קיימת באפליקציה הרשמית בלבד (חיווי עמדה: פנויה, תפוסה, תקולה, בהזמנה).
* **סוגי מחברים והספקים:**
  - AC Type 2 (עד 22kW)
  - DC Fast / Ultra-Fast CCS2 (הספקים מ-50kW ועד 300kW+)
  - CHAdeMO (בעמדות מדור קודם)
* **תעריפים ממוצעים:** AC כ-1.35–1.75 ₪ לקוט"ש; DC מהיר כ-2.20–2.90 ₪ לקוט"ש (משתנה לפי שעות שיא/שפל, דמי קישוריות ועמלות חניון).

### 2.2 PazCharge (קבוצת פז / אפליקציית yellow)
* **שם הספק:** פז Charge (קבוצת פז)
* **URL רשמי:** [https://www.paz.co.il](https://www.paz.co.il) (ניהול מרכזי באפליקציית `yellow`)
* **הערה לגבי פזגז:** פזגז מתמקדת בתשתיות אנרגיה ביתיות ואספקת חשמל ביתי ("פזגז חשמל"), בעוד שטעינת רכב מהירה בדרכים מרוכזת כולה תחת המותג **Paz Charge** בתחנות פז.
* **נקודת קצה (Endpoint):** אין API ציבורי פתוח. המערכת מנוהלת בפלטפורמת ה-CPMS של AMPECO המחוברת לשרתי קבוצת פז ואפליקציית yellow.
* **שיטת אימות (Authentication):** סגור; אימות משתמשים פנימי של פז/yellow (OAuth/JWT).
* **חינם או בתשלום:** סגור לפיתוח חיצוני.
* **מגבלות קצב (Rate Limits):** לא רלוונטי לציבור.
* **זמינות בזמן אמת (Real-time availability):** קיימת באפליקציית yellow (מצב תפיסות העמדות, הספק מירבי, תמיכה ב-AutoCharge).
* **סוגי מחברים והספקים:**
  - DC אולטרה-מהיר CCS2 (180kW עד 360kW ברוב מתחמי התדלוק)
  - מעט שקעי AC Type 2 (22kW)
* **תעריפים ממוצעים:** DC מהיר כ-2.30–2.60 ₪ לקוט"ש (הנחות מיוחדות לצוברי נקודות ב-yellow).

### 2.3 אפקון תחבורה חשמלית (Afcon EV / רשת ON)
* **שם הספק:** אפקון תחבורה חשמלית / Afcon ON
* **URL רשמי:** [https://www.on-ev.co.il](https://www.on-ev.co.il) | [https://afconev.co.il](https://afconev.co.il)
* **נקודת קצה (Endpoint):** אין API ציבורי פתוח. המערכת מנוהלת בשרתי ה-Back-office של אפקון ומזינה את אפליקציית `ON`.
* **שיטת אימות (Authentication):** פנימי בלבד (Session / App Token).
* **חינם או בתשלום:** סגור לציבור; חיבורי B2B מתבצעים באמצעות הסכמי נדידה (Roaming) בפרוטוקול OCPI (למשל מול Cello / חברות ליסינג).
* **מגבלות קצב (Rate Limits):** לא רלוונטי לציבור.
* **זמינות בזמן אמת (Real-time availability):** קיימת באפליקציית ON ובאפליקציית CelloCharge.
* **סוגי מחברים והספקים:**
  - AC Type 2 (עד 22kW)
  - DC Fast CCS2 (50kW, 120kW, 180kW+)
  - CHAdeMO (בחלק מהעמדות)
* **נתח שוק במאגר הממשלתי:** המפעיל הגדול ביותר במאגר הממשלתי עם **503 אתרי טעינה**.

### 2.4 אלקטרה פאוור / אלקטרה EV (קבוצת אלקטרה)
* **שם הספק:** אלקטרה פאוור (לשעבר סופרגז) / אלקטרה פתרונות חניה / אלקטרה מזגנים
* **URL רשמי:** [https://electra-power.co.il](https://electra-power.co.il) | [https://www.electraparking.co.il](https://www.electraparking.co.il)
* **הבהרה קריטית:** יש להבדיל בין רשת *Electra* האירופית (מפעילת DC גדולה באירופה בעלת ממשק OCPI פתוח לשותפים בכתובת `ocpi.go-electra.com`) לבין קבוצת אלקטרה בישראל. בישראל אלקטרה מתמקדת בהתקנת עמדות ביתיות, חניונים מוסדיים ומכפילי חניה.
* **נקודת קצה (Endpoint):** אין API ציבורי בישראל.
* **שיטת אימות (Authentication):** לא רלוונטי.
* **חינם או בתשלום:** לא רלוונטי.
* **זמינות בזמן אמת (Real-time availability):** אין רשת ארצית ציבורית פתוחה בעלת API.
* **סוגי מחברים:** עמדות AC Type 2 (11kW-22kW) במתחמים סגורים ובנייני מגורים.

---

### 2.5 Chakratec (ZOOZ Power) / Gnrgy (ג'ינרג'י) / עמדות עירוניות
* **ZOOZ Power (לשעבר Chakratec):**
  - **מהות:** חברת טכנולוגיית חומרה (מפתחת מאיצי טעינה מבוססי גלגלי תנופה קינטיים - Power Boosters).
  - **URL:** [https://zoozpower.com](https://zoozpower.com)
  - **API:** אינה מפעילת רשת צרכנית (CPO) ואינה מציעה API לחיפוש עמדות, אלא מוכרת ציוד למפעילים כמו אפקון ודור אלון.
* **Gnrgy (ג'ינרג'י):**
  - **מהות:** רשת טעינה ציבורית ועירונית ותיקה בישראל (אפליקציות `Gnrgy Go` ו-`Gnrgy Flexi`).
  - **URL:** [https://www.gnrgy.co.il](https://www.gnrgy.co.il)
  - **API:** אין API ציבורי פתוח. תקשורת פנימית מבוססת OCPP.
  - **מחברים:** AC Type 2 ו-DC CCS2.
* **עמדות עירוניות (כגון עיריית תל אביב-יפו / אחוזות החוף):**
  - הרשויות המקומיות אינן מפתחות API עצמאי, אלא מוציאות מכרזים למפעילים פרטיים (כגון EV-Edge, ג'ינרג'י, סונול EVI).
  - ניהול הטעינה, המידע והתשלום נעשה באפליקציית המפעיל הזוכה.

### 3.1 data.gov.il — מאגר AGG_CHARGE_STATIONS (משרד התחבורה והאנרגיה)
זהו מאגר הנתונים הממשלתי הרשמי והפתוח לציבור, הנגיש חינם לחלוטין.

* **שם המקור:** עמדות טעינה לרכב חשמלי (`agg_charge_stations`)
* **דף המאגר:** [https://data.gov.il/dataset/agg_charge_stations](https://data.gov.il/dataset/agg_charge_stations)
* **Dataset ID:** `6910f861-4a90-4c40-a2c6-09dbc4bcd4a7`
* **Resource ID (CSV Datastore):** `528482f2-d410-4d62-8b17-566ab23a1c52`
* **נקודת קצה לבדיקה (REST / CKAN Datastore Search):**
  ```http
  GET https://data.gov.il/api/3/action/datastore_search?resource_id=528482f2-d410-4d62-8b17-566ab23a1c52&limit=100
  ```
* **שיטת אימות (Authentication):** ללא אימות (פתוח לחלוטין לכל פנייה ברשת).
* **חינם או בתשלום:** **חינם לחלוטין (Free Open Government Data)**.
* **מגבלות קצב (Rate Limits):** אין הגבלה רשמית קשיחה, אך מומלץ לבצע שמירה מקומית (Caching) של הנתונים.
* **זמינות בזמן אמת (Real-time availability):** **לא (סטטי בלבד)**. הנתונים מתעדכנים תקופתית ע"י משרד התחבורה והאנרגיה.

### 3.2 משרד האנרגיה והתשתיות — מאגר הנתונים הלאומי (בשיתוף CelloCharge)
* **שם המקור:** מאגר עמדות הטעינה הלאומי בזמן אמת (משרד האנרגיה)
* **URL פורטל ממשלתי:** [https://www.gov.il](https://www.gov.il) (טופס בקשה לקבלת נתוני עמדות טעינה לרכב חשמלי)
* **שותף טכנולוגי ואפליקציה לאומית:** **CelloCharge** ([https://cellocharge.com](https://cellocharge.com))
* **פרוטוקול תשתית:** **OCPI 2.2+** (Open Charge Point Interface). המפעילים בישראל מחויבים רגולטורית להתחבר ולהזרים נתונים.
* **נקודת קצה (Endpoint):** שרת REST API של המאגר הלאומי (מועבר למפתחים מורשים לאחר אישור).
* **שיטת אימות (Authentication):** דורש מפתח API / Bearer Token המונפק לאחר הגשת טופס בקשה רשמי למשרד האנרגיה.
* **חינם או בתשלום:** **חינם בכפוף לאישור משרד האנרגיה** למיזמים ואפליקציות העומדות בקריטריונים.
* **מגבלות קצב (Rate Limits):** מוגדר לפי הרשאת ה-Token המאושרת.
* **זמינות בזמן אמת (Real-time availability):** **כן מלאה** (סטטוס עמדה פנוי/תפוס/תקלה, הספק טעינה בפועל, תעריף נוכחי).
* **סוגי מחברים מכוסים:** Type 2 AC, CCS2 DC, CHAdeMO.

### 3.3 GovMap GIS API (המרכז למיפוי ישראל)
* **שם המקור:** GovMap API
* **URL רשמי:** [https://www.govmap.gov.il](https://www.govmap.gov.il)
* **Endpoint:** ממשק JavaScript API ושכבות WFS/ArcGIS REST.
* **שיטת אימות (Authentication):** רישום מפתח מפתח (GovMap API Key) בחינם באתר GovMap.
* **חינם או בתשלום:** חינם לשימוש הציבור.
* **שימוש מומלץ:** המרת כתובות עמדות הטעינה מ-data.gov.il לקואורדינטות (Geocoding) מדויקות בישראל (רשת ישראל החדשה ITM או WGS84).

## 4. אגרגטורים ומקורות גלובליים פתוחים (Global Aggregators)

### 4.1 OpenStreetMap (OSM) / Overpass API
* **שם המקור:** OpenStreetMap (OSM)
* **Endpoint (Overpass QL):** `https://overpass-api.de/api/interpreter`
* **דוגמת שאילתת Overpass לקבלת עמדות בישראל:**
  ```text
  [out:json][timeout:25];
  node["amenity"="charging_station"](29.4,34.2,33.4,35.9);
  out body;
  ```
* **שיטת אימות (Authentication):** ללא אימות (Anonymous).
* **חינם או בתשלום:** **חינם לחלוטין (רישיון פתוח ODbL)**.
* **מגבלות קצב (Rate Limits):** מגבלת עומס הוגן (Fair Use) על שרתי Overpass הציבוריים; מומלץ לשמור עותק מקומי (dump) או להשתמש בשרת Overpass פרטי.
* **זמינות בזמן אמת:** לא (מידע סטטי קהילתי בלבד).
* **סוגי מחברים מכוסים:** כולל תגיות `socket:type2`, `socket:type2_combo`, `socket:chademo`, `capacity`, `operator`.

### 4.2 Open Charge Map (OCM) REST API
* **שם המקור:** Open Charge Map (OCM)
* **URL רשמי:** [https://openchargemap.org](https://openchargemap.org)
* **Endpoint (v3 POI API):**
  ```http
  GET https://api.openchargemap.io/v3/poi/?countrycode=IL&maxresults=500&output=json
  ```
* **שיטת אימות (Authentication):** דורש מפתח API חינמי (בכותרת `X-API-Key` או כפרמטר `key=...`). בדיקת קריאה ללא מפתח מחזירה `403 Forbidden`.
* **חינם או בתשלום:** **חינם** (ברישום מפתח מפתח פשוט באתר).
* **מגבלות קצב (Rate Limits):** עד מספר אלפי קריאות ביום למפתח חינמי.
* **זמינות בזמן אמת:** חלקית (מבוסס על דיווחי משתמשים ואינטגרציות OCPI גלובליות).
* **יתרון מפתח לבוט:** תומך בחיפוש ישיר לפי רדיוס מקואורדינטות משתמש:
  `https://api.openchargemap.io/v3/poi/?latitude=32.0853&longitude=34.7818&distance=10&distanceunit=KM&countrycode=IL`

### 4.3 PlugShare / TomTom / HERE EV APIs
* **PlugShare API:**
  - המאגר המקיף ביותר בעולם לחוות דעת וסטטוסים, אך ה-API **אינו פתוח לציבור** ודורש הסכם מסחרי יקר מול חברת EVgo.
* **TomTom EV Charging API:**

## 6. המלצה מנומקת וארכיטקטורה מומלצת לבוט

### 6.1 המקור הכי מבטיח לבוט חינמי בישראל (המלצה מדורגת)

עבור בוט טלגרם **חינמי, מהיר ועצמאי**, מומלצת ארכיטקטורה היברידית המבוססת על **3 שלבים**:

#### שלב א': השקה מיידית (Day 1) — חינם לחלוטין וללא תלות באישורים
1. **מאגר הנתונים הראשי:** שליפת כל 2,261 העמדות מ-`data.gov.il` באמצעות ה-CKAN API:
   `https://data.gov.il/api/3/action/datastore_search?resource_id=528482f2-d410-4d62-8b17-566ab23a1c52&limit=3000`
2. **גיאוקודינג וקואורדינטות (Geocoding):** המרת שדות הכתובת (`Address` + `name`) לקואורדינטות WGS84 (Lat/Lng) באמצעות GovMap Geocoder או Nominatim/OSM חד-פעמית, ושמירתם ב-SQLite / PostgreSQL (PostGIS) מקומי בשרת הבוט.
3. **חיפוש מבוסס מיקום בטלגרם:** כאשר המשתמש שולח "Share Location" בטלגרם, הבוט מבצע שאילתת רדיוס מרחבית (Haversine / Spatial Index) על בסיס הנתונים המקומי ומחזיר את העמדות הקרובות ביותר, כולל שם המפעיל (Afcon, EV-Edge, Sonol וכו') וכמות עמדות מהירות/איטיות.
4. **גיבוי שאילתות דינמי:** שימוש ב-**Open Charge Map API** עם מפתח חינמי לשאילתות רדיוס משלימות.

#### שלב ב': שדרוג לזמן אמת (Real-Time) — הגשת בקשה למשרד האנרגיה
* **המהלך המומלץ:** פנייה דרך אתר Gov.il ב"טופס בקשה לקבלת נתוני עמדות טעינה לרכב חשמלי" עבור פרויקט הבוט.
* **התוצאה:** קבלת גישה ל-API הלאומי הרשמי המופעל ע"י CelloCharge, המאפשר להציג בבוט סטטוס חם: *🟢 פנוי / 🔴 תפוס / ⚠️ תקלה*, יחד עם תעריף מדויק והספק ב-kW.

### 6.2 החלופה הטובה ביותר בתשלום / ברמה מסחרית
אם הפרויקט עובר למודל מסחרי או דורש SLA מובטח:
1. **TomTom EV Charging Points API:** האפשרות המובילה לאגרגציה מסחרית גלובלית, כולל ניתוב חכם לפי טווח סוללה (EV Routing API).
2. **הסכם OCPI Hub / נדידה מסחרי מול CelloCharge או אחד מגדולי ה-CPOs (כגון Driivz / אפקון / EV-Edge):** קבלת גישה ישירה לפידי נתונים עסקיים בזמן אמת.
